## Key Learnings

### Custom Distribution OAuth Flow

**How it works:**
```
1. Create custom app in Shopify Partners for each customer
2. Add client_id + client_secret to shopify_apps table
3. Customer clicks install link
4. OAuth callback receives shop domain + code
5. Backend looks up credentials by shop_domain
6. Exchange code for access_token using customer's credentials
7. Save token to shops table
8. Link shop to user via user_id
```

**Why per-customer credentials:**
- Security: Shopify verifies client_secret on token exchange
- Isolation: Each customer's app is separate
- Control: Can revoke individual apps without affecting others

### Database Architecture

**User → Shop Linking:**
```
users.id (14) ←→ shops.user_id (14) → shops.access_token
```

**Key Tables:**
- `users`: User accounts (email, approved)
- `shops`: Shopify connections (shop_domain, access_token, user_id)
- `shopify_apps`: App credentials (client_id, client_secret per customer)
- `products`: Synced Shopify products
- `recommendations`: AI price suggestions
- `user_activity_log`: All user actions
- `elasticity_learners`: Learned price elasticity per product
- `regret_budgets`: Regret minimization state

**Access Token Flow:**
```javascript
// Always fetch from shops table, not users table
const { data: shopData } = await supabaseService
  .from('shops')
  .select('shop_domain, access_token')
  .eq('user_id', userId)
  .eq('is_active', true)
  .single();
```
